# 293查询 · 综合信息查询站（前端仿站版）

仿制目标：<https://www.293.net/> —— 一个以 Bootstrap 卡片栅格排列的「综合信息查询」导航站。

本工程为**纯前端静态站**（HTML + CSS + 原生 JS + jQuery + Bootstrap），双击 `index.html` 即可本地运行，无需后端、无需构建。

## 目录结构

```
293clone/
├── index.html            首页（导航栏 + 9 张工具卡，1:1 还原源站布局）

├── sfz.html              身份证归属地查询
├── bank.html             银行卡归属地查询

```

## 各工具的可用性

| 工具 | 说明 |
| --- | --- |
| IP 查询 | **真实可用**：调用公开接口（ipapi.co，失败回退 ip-api.com）查询归属地/运营商/经纬度/时区，打开页面自动显示本机 IP |
| 安全期计算 | **真实可用**：本地按周期算法计算排卵期/安全期/下次月经，纯前端 |
| 网名生成 | **真实可用**：本地词库随机组合，点击复制 |
| QQ 价格评估 | **真实可用**：按位数/连号/顺子/ABAB/吉祥数字打分估价（娱乐向） |
| 邮编 / 区号 | **真实可用**：内置常见城市示例库，支持名称与编码双向查询 |
| 备案查询 | 跳转工信部官方系统 `beian.miit.gov.cn`（备案库属国家管理，仿站不内置） |
| 身份证归属地 | 依据**公开的行政区划代码**做静态映射 + 18 位校验位校验，不联网、不采集隐私 |
| 银行卡归属地 | 依据**公开卡 BIN 号段**做静态映射演示，标注免责声明，不查询任何真实卡片信息 |

> ⚠️ 含个人隐私属性的查询（身份证/银行卡），本 Demo 仅做"公开编码 → 名称"的本地映射演示，**不接入任何真实数据源**，请勿用于侵犯他人隐私的用途。

## 本地运行

直接双击 `index.html`，或起个静态服务：

```bash
python -m http.server 8090
# 浏览器访问 http://127.0.0.1:8090/index.html
```

> 提示：IP 查询依赖网络接口，本地 `file://` 打开也可用（跨域接口已支持 CORS）。

## 二次开发

- 改导航/页脚：编辑 `js/layout.js`
- 改工具逻辑或数据：编辑 `js/tools.js`（数据以对象形式内联，便于替换成真实接口）
- 改工具页版式：编辑 `build_pages.py` 的 `TOOLS` 模板后重新 `python build_pages.py`
