1 🚀 修改 7Tan，让它不断升级进化

7Tan 的全部代码就在你下载的包里，解压后（以 v1.0.20 为例）结构如下：

📦  Windows版（7tan-editor-*.zip）
├─ 7tan-editor\                  ← 主程序（exe + 运行时，双击即用）
├─ 7tan-src\                     ← 全部源码与资源（可改造区）
│  ├─ src\                       ← 主程序源码（Python）
│  │  └─ web\static\             ← 网页版前端（HTML / CSS / JS）
│  ├─ data\                      ← 数据与记忆（含 plugins\ 插件）
│  └─ build.bat                  ← 重新构建
├─ 7Tan使用说明书.html / .md
└─ 启动网页版服务(Windows).bat

📦 通用版（7tan-web-*.zip）
├─ src\                          ← 主程序源码（Python）
│  └─ web\static\                ← 网页版前端（HTML / CSS / JS）
├─ data\                         ← 数据与记忆（含 plugins\ 插件）
├─ config\                       ← 配置
├─ tools\                        ← 内置工具
├─ main.py / web_main.py         ← 程序入口
└─ 启动网页版服务(Linux).sh / (macOS).command

💻 Windows 版里怎么用 WEB 版？

  1. 启动：解压后双击根目录的 启动网页版服务(Windows).bat，脚本会自动安装网页服务开机自启并启动，随后自动打开浏览器进入 http://127.0.0.1:9900/。
  2. 日常使用：自启安装成功后，以后每次开机网页版都会自动运行，直接访问 http://127.0.0.1:9900/ 即可，无需再手动启动。
  3. 手机访问：同一 WiFi 下用 http://电脑IP:9900（如 http://192.168.2.10:9900）即可；出门在外可用 Cloudflare 隧道公网地址。
  4. 与桌面版互通：桌面版（7tan-editor\）和网页版共用同一份 data\ 数据与插件，可随时切换、同时使用。
💡 Windows 用户一个包全搞定：要桌面版就双击 7tan-editor\7tan-editor.exe，要网页版就双击 启动网页版服务(Windows).bat，两个都能用，数据互通。

三种改造方式（从易到难）

  1. 改网页外观/文字：直接编辑 src\web\static\（桌面版为 7tan-src\src\web\static\）下的 index.html、style.css、app.js，保存后刷新浏览器（Ctrl+F5）立即生效，不用重启。
  2. 改核心功能：修改 src\（桌面版为 7tan-src\src\）下的 Python 代码后，对 7Tan 说一句"重启生效"即可；桌面版如需重新打包，运行 7tan-src\build.bat。
  3. 获取官方更新：重新下载新版压缩包，解压后覆盖到原目录即可（data\ 里的数据与插件会保留）。
💡 最省事的升级方式：你不需要自己写代码！直接对 7Tan 说："帮我加一个 XX 功能 / 把 XX 改成 XX"，它会自己改代码、自己重启、自己测试，你只负责验收。

3 🧩 给 7Tan 制作你自己想要的插件

7Tan 支持插件体系：每个插件就是一组"工具代码"（tools.py），注册后 7Tan 就能调用它完成新任务。插件 = 新技能。

插件由四个要素构成

plugin_id   : 唯一标识，如 "weather_plugin"
plugin_name : 显示名称，如 "每日天气"
description : 描述它能干什么（AI 靠这个决定何时调用）
tools_code  : Python 代码，定义 1~N 个工具函数

方式一：让 7Tan 帮你做（推荐，零代码）

直接在对话框里说：

"创建一个天气插件，功能：输入城市名返回实时天气和穿衣建议"

7Tan 会自动：编写插件代码 → 注册到系统 → 重启生效 → 告诉你测试方法。

方式二：自己写一个最简单的插件

在 data\plugins\（桌面版为 7tan-src\data\plugins\）下新建目录，写一个 tools.py，例如"今日一句"插件：

# data/plugins/quote_plugin/tools.py
def daily_quote():
    """返回一句今日名言（AI 会把这个函数注册为工具）"""
    quotes = [
        "行动是治愈恐惧的良药。",
        "千里之行，始于足下。",
        "种一棵树最好的时间是十年前，其次是现在。",
    ]
    import datetime
    return quotes[datetime.date.today().day % len(quotes)]

然后对 7Tan 说"注册我的 quote_plugin 插件"，它会把函数接入工具系统。

⚠️ 注意：插件注册后通常需要重启才生效；写插件时注意函数要返回可序列化的文本/字典，别写死循环。

? ❓ 常见问题

  • 改坏了怎么办？ 重新解压一份原始压缩包到另一个文件夹上，不要覆盖回去，再点击 EXE 叫它对改坏的进行修复；WEB 版可以重启后再进行修复。反正 7Tan 就像打不死的小强，随时可以满血复活。最后还可以找我们或网友大神帮忙，在界面左侧底部有 7坛社区、问题求助 等。
  • 改了网页没变化？ 浏览器缓存了旧文件，按 Ctrl+F5 强制刷新即可。
  • 插件注册了不生效？ 重启 7Tan 后再试；检查插件函数是否有语法错误（可在沙盒里先跑一遍）。
  • 远程访问总掉线？ 那是 Cloudflare 免费隧道域名会变，可在「系统设置 → 远程访问」查看最新地址，或配置固定域名。
  • 完全不会编程能改吗？ 能。所有改造都可以用对话完成——你只负责说想法，7Tan 负责写代码。
