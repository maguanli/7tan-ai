## 一、软件简介

**7Tan**（7坛 AI 小编「盘古」）是一款**免费使用**的 AI 智能工作台（个别高级插件需付费解锁），把**编程写代码、AI 对话、游戏采集发布、内容创作**整合在一起，让重复劳动变成一句话指令。

### 1.1 它能做什么

| 能力 | 说明 |
|:--|:--|
| 💻 编程写代码 | **首要能力**：AI 编写/修改代码、代码补全、代码审查、Git、Docker/K8s、CI/CD、测试与部署，全栈开发一条龙 |
| 💬 AI 对话 | PyQt6 聊天式交互，Markdown 渲染、流式输出、思考过程 |
| 🎮 游戏发布 | 自动浏览源站、提取素材、OSS 上传、后台自动填表发布 |
| ✍️ AI 撰写 | 深度分析游戏 + 生成 HTML 游戏简介，支持英译中 |
| 🧩 插件系统 | 35+ 插件、142+ 工具，热插拔扩展能力（绝大多数免费，个别高级插件付费） |
| 🚀 自我进化 | AI 可以修改自身代码、创建插件、自我升级 |

### 1.2 典型使用场景

- **全栈开发（首要场景）**：让 AI 写代码、改代码、跑测试、Git 提交、Docker 部署、服务器运维；
- **游戏编辑**：把整理好的游戏资料（LOGO、截图、简介）一键发布到 7坛 后台；
- **内容采集**：从 TapTap / 9game / Steam 等源站自动抓取新游信息；
- **内容创作**：公众号爆款文章、封面图、金句卡片、视频配音；
- **生活娱乐**：易经占卦、孙子兵法决策、智能翻译。

## 三、系统要求与安装

### 3.1 系统要求

| 项目 | 要求 |
|:--|:--|
| 操作系统 | Windows 10 / 11（64 位） |
| 内存 | 建议 4GB 及以上 |
| 磁盘 | 安装后约 500MB，另需下载/素材缓存空间 |
| 网络 | 需要联网（AI 对话、发布、更新） |

### 3.2 安装步骤

1. 解压 `7tan-editor-free-v1.0.9.zip` 到任意目录（**路径不要包含中文和空格**，如 `D:\7tan-editor`）；
2. 进入解压后的 `7tan-editor` 文件夹；
3. 双击 **`7tan-editor.exe`** 启动软件；
4. 首次启动会弹出**欢迎向导**，按提示完成基础配置。

> 💡 建议右键 exe → 发送到 → 桌面快捷方式，方便日常启动。

### 3.3 目录结构说明

```
7tan-editor/
├── 7tan-editor.exe        # 主程序（双击运行）
├── _internal/             # 运行所需的内置文件（请勿删除）
├── 7Tan使用说明书.md      # 使用说明书（Markdown 版）
├── 7Tan使用说明书.html    # 使用说明书（网页版，双击即可阅读）
└── （运行后自动生成）
    ├── data/              # 数据目录（数据库、日志、插件）
    ├── logs/              # 运行日志
    ├── downloads/         # 下载缓存
    └── config.yaml        # 全局配置文件
```

### 6.1 💬 AI 对话

- **输入方式**：底部输入框输入自然语言指令，回车发送；
- **Markdown 渲染**：回复中的标题、列表、表格、代码块自动美化显示；
- **流式输出**：AI 回复逐字显示，可随时查看进度；
- **思考过程**：可展开查看 AI 的推理步骤；
- **历史会话**：左侧列表切换；支持重命名、删除、搜索；
- **Token 显示**：对话右上角显示本次消耗 Token 数。

**常用指令示例**

```
- 帮我发布《XX游戏》：资料在 路径，LOGO 截图都在里面
- 抓取 TapTap 首页新游

- 把这段英文介绍翻译成中文
- 检查 7Tan 后台今天发布了几款游戏
```

### 6.2 🎮 游戏采集与发布（核心功能）

**发布前准备**：把游戏资料整理到同一个文件夹：

```
D:\用户目录\下载\新建文件夹 123\11\
├── 游戏资料.txt      # 标题、简介、开发商、备案号、下载链接等
├── logo.png          # 游戏 LOGO
└── 1.jpg 2.jpg ...   # 游戏截图（2~5 张）
```

**告诉 AI 发布**（示例）：

```
我已经把《鬼魂》的资料整理到 D:\用户目录\下载\新建文件夹 123\11，
请帮我到管理后台发布，LOGO 与截图都在里面，其他资料在游戏资料.txt，
简介不用修改，安装包不用下载，把下载链接加上发布。
```

**AI 自动执行流程**：

```
读取资料 → 数据库查重（不重复发布）→ 压缩图片（LOGO+截图）
→ 登录 7坛 后台 → 选择栏目 → 上传 LOGO/截图 → 填写表单
→ 提交发布 → 后台列表验证 → 敏感词/内容质量检查 → 入库登记
```

**发布结果示例**（AI 会汇报）：

```
✅ 发布成功！
标题：鬼魂（ID 994）  栏目：冒险解密
开发商：海南星空跳动科技有限公司   系统要求：5.0
LOGO：已上传（512x512）   截图：5 张
前台链接：https://www.7tan.com/game/994/
```

> ⚠️ 注意：告诉 AI **「是发布不是替换」**，避免 AI 误操作覆盖已有游戏。

### 6.3 🌐 浏览器与素材工具

## 十、常见问题 FAQ

### 1. 更新时提示「无法启动更新程序: Read timed out」？

> 旧版本（≤1.0.7）的已知问题：更新解压会卡住本地服务导致超时。**升级到 1.0.8 及以上已修复**。请手动下载新版安装包升级一次即可。

### 2. 录屏没有声音？

> 检查「设置 → 录屏 → 音频设备」是否选择了正确的录音设备（如「立体声混音」或麦克风）。若设备不可用，软件会提示；请先在 Windows 声音设置中启用录音设备。

### 3. 点击历史对话时鼠标变圈圈、界面卡顿？

> 旧版本加载大量历史消息时性能不佳。**1.0.8 已优化**（渐进渲染 + 高度同步节流）。若仍卡顿，请升级到最新版。

### 4. 登录页点「忘记密码」没反应？

> 1.0.8 已修复（旧版点击会静默报错）。升级后会自动打开浏览器访问找回密码页面：[https://www.7tan.com/bbs/77562/](https://www.7tan.com/bbs/77562/)

### 5. 左侧底部点「刷新」报 404？

> 1.0.8 已修复 API 域名错误（图片服务器 vs 主站）。升级后刷新会正常返回「会员状态已更新」。

### 6. 软件闪退 / 崩溃怎么办？

1. 找到 `logs\crash_*.txt` 文件（记录崩溃原因）；
2. 查看 `logs\app_日期.log` 最近的报错；
3. 把这两个文件发给技术支持，便于定位修复；
4. 常见崩溃（浏览器控件被销毁等）已在后续版本修复，请保持更新。

### 7. 登录提示「账号或密码错误」？

> 1.0.7 已修复错误提示不准确的问题。请确认账号密码无误；如忘记密码，用登录页「忘记密码」链接找回。

### 8. 语音提示「语音引擎未就绪：请检查手机TTS中文语音包」？

> 该提示来自**易经 AI 占卦 APP**（安卓端），不是 7Tan 桌面版。原因是手机系统缺少 TTS 中文语音包。解决：安装 v0.10.0+ 版 APP（已内置离线语音引擎），或给手机安装中文语音包。

### 9. 杀毒软件/Windows Defender 拦截软件？

> 软件为正规开发，但因包含自动更新、自我修改能力，个别杀软可能误报。请添加信任/允许运行；如仍有疑问请联系官方。

### 10. 忘记后台密码 / 发布时提示登录失败？

> 检查「设置 → 站点设置」中的后台用户名密码；确认网络可访问后台域名；发布间隔建议保持 30 秒以上。

### 11. 如何反馈问题 / 求助？

> 软件左侧底部提供「问题求助 / 投诉建议」入口，或联系官网 [https://www.7tan.com](https://www.7tan.com) 客服。
