3.2 安装步骤

- 解压 `7tan-editor-free-v1.0.12.zip` 到任意目录（**路径不要包含中文和空格**，如 `D:\7tan-editor`）；
- 进入解压后的 `7tan-editor` 文件夹；
- 双击 **`7tan-editor.exe`** 启动软件；
- 首次启动会弹出**欢迎向导**，按提示完成基础配置。
💡 建议右键 exe → 发送到 → 桌面快捷方式，方便日常启动。


- **绿色版零依赖**：**无需安装 Python / Node.js** 等任何软件，exe 自带运行环境；用户移动 / 重命名软件目录后，只要再运行一次启动脚本（或 WEB 服务启动过），开机自启路径会自动校准修复。

##
十、常见问题 FAQ

###
1️⃣ 更新时提示「无法启动更新程序: Read timed out」？

旧版本（≤1.0.7）已知问题：更新解压会卡住本地服务导致超时。**升级到 1.0.8 及以上已修复**。请手动下载新版安装包升级一次。
###
2️⃣ 录屏没有声音？

检查「设置 → 录屏 → 音频设备」是否选择了正确的录音设备（如「立体声混音」或麦克风）。若设备不可用软件会提示，请先在 Windows 声音设置中启用录音设备。
###
3️⃣ 点击历史对话时鼠标变圈圈、界面卡顿？

旧版本加载大量历史消息时性能不佳。**1.0.8 已优化**（渐进渲染 + 高度同步节流）。若仍卡顿请升级到最新版。
###
4️⃣ 登录页点「忘记密码」没反应？

1.0.8 已修复（旧版点击会静默报错）。升级后会自动打开浏览器访问：[https://www.7tan.com/bbs/77562/](https://www.7tan.com/bbs/77562/)
###
5️⃣ 左侧底部点「刷新」报 404？

1.0.8 已修复 API 域名错误（图片服务器 vs 主站）。升级后刷新会正常返回「会员状态已更新」。
###
6️⃣ 软件闪退 / 崩溃怎么办？

- 找到 `logs\crash_*.txt`（记录崩溃原因）；
- 查看 `logs\app_日期.log` 最近报错；
- 把两个文件发给技术支持，便于定位修复；
- 常见崩溃（浏览器控件被销毁等）已在后续版本修复，请保持更新。
###
7️⃣ 登录提示「账号或密码错误」？

1.0.7 已修复错误提示不准确问题。请确认账号密码无误；忘记密码可用登录页「忘记密码」链接找回。
###
8️⃣ 语音提示「语音引擎未就绪：请检查手机TTS中文语音包」？

该提示来自 **易经 AI 占卦 APP（安卓端）**，不是 7Tan 桌面版。原因是手机系统缺少 TTS 中文语音包。解决：安装 v0.10.0+ 版 APP（已内置离线语音引擎），或给手机安装中文语音包。
###
9️⃣ 杀毒软件 / Windows Defender 拦截软件？

软件为正规开发，但因包含自动更新、自我修改能力，个别杀软可能误报。请添加信任 / 允许运行；如有疑问请联系官方。
###
🔟 忘记后台密码 / 发布时提示登录失败？

检查「设置 → 站点设置」中的后台用户名密码；确认网络可访问后台域名；发布间隔建议保持 30 秒以上。

软件左侧底部提供「问题求助 / 投诉建议」入口，或联系官网 [https://www.7tan.com](https://www.7tan.com) 客服。
