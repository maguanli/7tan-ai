7Tan WEB 版（其他操作系统通用包）
====================================
适用系统：macOS / Linux / 鸿蒙 PC 等非 Windows 系统
（Windows 用户请下载 Windows 专属完整包）

快速开始：
  1. 解压本 ZIP 到任意目录（路径建议不要含中文）
  2. 选择对应系统的启动脚本：
       macOS   → 双击「启动网页版服务(macOS).command」
                 （首次提示权限，请右键→打开）
       Linux   → 终端执行：bash 启动网页版服务(Linux).sh
  3. 脚本自动检查/安装依赖，并启动 http://127.0.0.1:9900/
  4. 浏览器打开 WEB 版后，按页面提示点击【确认适配】，
     7Tan 自动完成当前系统的插件复制适配，全部功能可用

系统要求：Python 3.10+（脚本会自动提示安装方法）

功能说明：
  - 完整 WEB 版：对话 / 编程 / 爬虫 / 写作 / 代码工具 / 记忆 / 统计等
  - Windows 专属插件（桌面控制、公众号发布）在非 Windows 系统
    自动适配或友好降级
  - 详细说明见《7Tan使用说明书.html》
