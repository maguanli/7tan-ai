三、系统要求与安装

3.1 系统要求

项目要求

3.2 安装步骤

  1. 解压 7tan-editor-free-v1.0.12.zip 到任意目录（路径不要包含中文和空格，如 D:\7tan-editor）；
  2. 进入解压后的 7tan-editor 文件夹；
  3. 双击 7tan-editor.exe 启动软件；
  4. 首次启动会弹出欢迎向导，按提示完成基础配置。
💡 建议右键 exe → 发送到 → 桌面快捷方式，方便日常启动。

WEB 版启动与登录（简单说明）

  1. 打开：浏览器直接访问 http://127.0.0.1:9900/ 即可使用；若提示无法访问，双击一次「Windows-启动网页版服务.bat」即可（自动启动服务、设置开机自启并打开浏览器），以后开机自动运行，随时直接访问；
  2. 登录：与桌面版同一账号，勾选《用户协议》《隐私政策》后登录；没有账号可在登录框点「注册」；
  3. 登录成功后即可在浏览器里 AI 对话、编程写代码、查看实时控制台。
💚 无需安装任何软件：绿色版解压即用，无需安装 Python / Node.js——exe 自带运行环境，浏览器访问 http://127.0.0.1:9900/ 即可使用。
⚠️ 系统要求：Windows 用户请下载使用 Windows 完整版绿色包（适用于 Windows 10 / 11 64 位）；macOS / Linux / 鸿蒙（HarmonyOS）用户请下载「其他系统包」，解压后按系统运行对应启动脚本即可（见 4.4）。
WEB 版详细功能与远程访问说明见 4.4 WEB 版快速上手。

4.4 WEB 版快速上手（浏览器控制台）

7Tan 除了桌面客户端，还自带 WEB 版——与桌面版同一个引擎、同一套账号与数据，用浏览器就能 AI 对话、编程写代码、查看实时控制台、远程操作电脑。

项目说明
访问地址http://127.0.0.1:9900/（WEB 版统一访问地址，服务启动后即可打开）
系统要求Windows 完整版包：Windows 10 / 11（64 位），绿色版免安装、解压即用；macOS / Linux / 鸿蒙 用户下载「其他系统包」，解压后运行对应启动脚本即可（见下）
账号登录与桌面版同一账号；登录框含《用户协议》《隐私政策》勾选，注册链接指向 7坛 论坛注册页
核心功能AI 对话 / 编程写代码、实时控制台、语音朗读（女声本地 Piper / 男声 Edge 在线）、消息复制 / 编辑 / 删除、时间显示年月日、登录状态与能力值
远程访问局域网 / 公网访问需在左上角填写 API Token（存放于 data\.api_token），本机访问可留空

如何使用

  1. 直接打开浏览器，访问 http://127.0.0.1:9900/ 即可使用（WEB 服务开机自启，通常已在运行）；
  2. 若提示无法访问，说明服务未启动：双击「Windows-启动网页版服务.bat」一次（自动启动服务、设置开机自启并打开浏览器），之后开机自动运行、随时直接访问。
🖱️ 按系统选择启动文件：Windows → 双击 Windows-启动网页版服务.bat；macOS → 双击 macOS-启动网页版服务.command；Linux / 鸿蒙 → 执行 Linux-启动网页版服务.sh（其他系统包首次运行会自动安装依赖并打开浏览器）。
💡 绿色版移动目录也不怕：每次双击「Windows-启动网页版服务.bat」都会自动校准开机自启路径；WEB 服务每次启动也会自动校准，移动文件夹后无需任何手动操作。
⚠️ 若 http://127.0.0.1:9900/ 打不开：先双击「Windows-启动网页版服务.bat」启动服务（会自动打开浏览器，并设置开机自启，以后无需手动启动）；仍不行请检查防火墙是否放行 9900 端口。

  • 远程访问（API Token）：本机访问无需 Token；局域网 / 公网设备访问时，需在左上角填写 API Token（存放于 data\.api_token）才能操作，防止他人控制你的电脑；

十、常见问题 FAQ

1️⃣ 更新时提示「无法启动更新程序: Read timed out」？

旧版本（≤1.0.7）已知问题：更新解压会卡住本地服务导致超时。升级到 1.0.8 及以上已修复。请手动下载新版安装包升级一次。

2️⃣ 录屏没有声音？

检查「设置 → 录屏 → 音频设备」是否选择了正确的录音设备（如「立体声混音」或麦克风）。若设备不可用软件会提示，请先在 Windows 声音设置中启用录音设备。

3️⃣ 点击历史对话时鼠标变圈圈、界面卡顿？

旧版本加载大量历史消息时性能不佳。1.0.8 已优化（渐进渲染 + 高度同步节流）。若仍卡顿请升级到最新版。

4️⃣ 登录页点「忘记密码」没反应？

1.0.8 已修复（旧版点击会静默报错）。升级后会自动打开浏览器访问：https://www.7tan.com/bbs/77562/

5️⃣ 左侧底部点「刷新」报 404？

1.0.8 已修复 API 域名错误（图片服务器 vs 主站）。升级后刷新会正常返回「会员状态已更新」。

6️⃣ 软件闪退 / 崩溃怎么办？

  1. 找到 logs\crash_*.txt（记录崩溃原因）；
  2. 查看 logs\app_日期.log 最近报错；
  3. 把两个文件发给技术支持，便于定位修复；
  4. 常见崩溃（浏览器控件被销毁等）已在后续版本修复，请保持更新。

7️⃣ 登录提示「账号或密码错误」？

1.0.7 已修复错误提示不准确问题。请确认账号密码无误；忘记密码可用登录页「忘记密码」链接找回。

8️⃣ 语音提示「语音引擎未就绪：请检查手机TTS中文语音包」？

该提示来自 易经 AI 占卦 APP（安卓端），不是 7Tan 桌面版。原因是手机系统缺少 TTS 中文语音包。解决：安装 v0.10.0+ 版 APP（已内置离线语音引擎），或给手机安装中文语音包。

9️⃣ 杀毒软件 / Windows Defender 拦截软件？

软件为正规开发，但因包含自动更新、自我修改能力，个别杀软可能误报。请添加信任 / 允许运行；如有疑问请联系官方。

🔟 忘记后台密码 / 发布时提示登录失败？

检查「设置 → 站点设置」中的后台用户名密码；确认网络可访问后台域名；发布间隔建议保持 30 秒以上。
