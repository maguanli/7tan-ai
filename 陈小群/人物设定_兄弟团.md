# 《游资是怎样炼成的》人物设定·兄弟团（修订版2）

> 主角：陈晓（原型陈晏群/陈小群「心跳r」），30万入市（亏两年剩8万），最终做到数亿→峰值15亿。
> 本文档设定陈晓身边的"炒股兄弟/朋友/亲戚"，贯穿全书，承载"一将功成万骨枯"的真相。
> 核心设定：**最终成为游资的，包括陈晓在内共三人（陈晓 + 阿凯 + 林薇）；其余大部分亏损惨重离场。**
> 三种成功路径（龙头战法 / 爆仓重生 / 稳健复利）+ 五种失败死法（温水煮青蛙 / 杠杆爆仓 / 挪用公款配资 / 跟单被割 / 卖房网贷）+ 无数龙套散户。
> 另有江湖对标人物：**六一路**（2024年神秘格局游资，"格局"的奠基人，陈晓的镜子）。

## 二、人物小传

### 1. 陈晓（回本再走）——主角，顶级游资

- **身份**：25岁北漂，普通家庭、普通学历，白天打工晚上复盘。
- **性格弧光**：赌徒式追高 → 纪律机器 → 敬畏市场的王者。
- **战法**：情绪合力龙头（情绪周期六阶段 + 只做最强 + 冰点低吸 + 分歧上车 + 高潮兑现 + 退潮空仓）。
- **命运线**：30万(2018)→8万(2020.3)→5.9万(割肉后)→20万(2020.7)→100万(2021.12)→3200万(2022一年32倍) → 1.5亿(2023 AI) → 10亿(2024 924) → 峰值15亿→数亿(2025危机)。
- **结局**：2025.12站在巅峰，却面临监管/舆论的刀悬头顶，最终抉择"功成身退"。

### 2. 林凯（阿凯）——爆仓后重生的游资

- **身份**：陈晓在淘股吧认识的同龄人，程序员，脑子快，数学好，自称"技术派"。
- **性格**：聪明、自负、好胜。看不起"土办法"，喜欢搞量化、搞模型。赌性重，喜欢"一把定胜负"。
- **入市**：2021年在淘股吧看到陈晓的复盘帖，主动加好友，两人深夜论战，亦敌亦友。
- **命运线**（关键，三段式）：
  1. **巅峰前夜**：2021年九安医疗满仓梭哈，赚得比陈晓还多；2022年两人并驾齐驱，阿凯一度觉得"陈晓太保守"。
  2. **爆仓坠落**：2023年AI行情，阿凯满仓+融资梭哈一只算力票，账户一度冲到几千万、超过陈晓；结果AI高位巨震，被强平，几千万一天归零，还欠下券商融资债。他差点失联，是陈晓拼命把他找回来、拉了他一把，帮他还了债，点醒他："活着才有机会。"
  3. **重生成功**：阿凯痛定思痛，戒掉赌性，转型做"稳健套利"（可转债、ETF、低风险套利），从零开始。靠纪律慢慢做起来，最终成为规模较小但稳定盈利的游资。
- **结局**：成功成为游资，规模虽远不如陈晓，但活得好好的。他成了陈晓"还活着"的镜子。
- **作用**：全书最重要的对照线之一。阿凯证明了：**天赋只能送你到半山腰，纪律才能送你到山顶；爆仓不是终点，认输才是。**
- **关键台词**：
  - "陈晓，你这套太慢了，我一把就超过你。"
  - "看对了就要上满仓，不然赚什么钱？"
  - "（爆仓后）别回我消息了……我认了。"
  - "（重生后）我现在一天只赚几百块，但睡得着觉了。"

### 3. 林薇——稳健复利的中型游资

- **身份**：比陈晓大两岁，在券商营业部上班，接触过机构客户，对市场有敬畏心。
- **性格**：冷静、理性、克制。说话慢条斯理，像大姐姐。
- **入市**：2018年就入市了，经历完整轮熊市，被教育过。
- **炒股风格**：只做趋势明确的票，不追高、不打板、不碰妖股。仓位分散，回撤控制极好，收益率不算暴利但极其稳定。
- **命运线**：
  - 2020-2024：稳稳当当，牛市赚一点，熊市少亏一点，账户**复利缓慢增长**，从几十万一步步做到几千万，成为**中型游资**。
  - 她从不羡慕陈晓的暴利，也不被老周、张鹏的惨状动摇，坚持自己的节奏。
  - 2025年：把手里的钱取出来，回老家开小店，**彻底隐退、全身而退**。
- **结局**：成功成为游资，且在巅峰时主动离场——她是全书里唯一"赢得漂亮又退得干净"的人。
- **作用**：给全书一条"普通人的正确成功路"。林薇证明：**不一定非要打板梭哈才能成为游资，复利 + 纪律 + 敬畏，同样能走到终点，而且走得稳。**
- **关键台词**：
  - "陈晓，你这钱赚得我替你捏把汗。"
  - "仓位管理比选股重要，这句话我送你。"
  - "你赚的是命，我赚的是心安。"

### 4. 周海（老周）——最普遍的散户（失败·温水煮青蛙）

- **身份**：陈晓发小，两人同在北京打工，周海在物流公司开叉车。比陈晓大两岁，嗓门大、爱吹牛、讲义气。
- **性格**：急脾气，听风就是雨，别人说哪个票好就追哪个。赚了请客喝酒，亏了就骂娘。
- **炒股风格**：完全没有体系，靠群里消息、大V喊单。追涨杀跌，赚小钱就跑，套牢就死扛，扛不住就割在地板。
- **命运线**：2020年牛市跟风赚点小钱飘了 → 2021年反复追高被套、借钱补仓 → 2022年熊市彻底爆仓，欠十几万外债，回老家打工还债。
- **作用**：陈晓的一面镜子。老周身上全是陈晓"本可能成为的样子"——如果没有悟道、没有纪律，陈晓就是下一个老周。死法是"温水煮青蛙"：不设止损，慢慢被熬死。
- **关键台词**：
  - "兄弟，我跟你说，这个票明天肯定涨停，内幕消息！"
  - "妈的又套了，先扛着，总会回来的。"
  - "陈晓你听我的，别整那些虚的，跟着热点买就完了。"

### 5. 张鹏（胖子）——最惨的悲剧（失败·杠杆爆仓）

- **身份**：陈晓同乡，在北京开小饭馆，手里攒了六七十万，有点家底。胖，爱笑，豪爽，人缘好。
- **性格**：胆子大，信"富贵险中求"。觉得打工开店太慢，想靠股市翻身。
- **炒股风格**：满仓 + 加杠杆（场外配资）。赚了加码，亏了也加码，坚信"扛过去就是牛市"。
- **命运线**：2020.7券商牛加杠杆吃到翻倍 → 2021年锂电继续加杠杆一度赚到两百多万、彻底飘了 → 2022年熊市杠杆爆仓、一天被强平，两百多万归零还倒欠几十万 → 饭馆抵了、老婆带孩子回娘家，楼顶差点跳下去，被陈晓死死拽住。后靠打工还债，重新做人。
- **作用**：全书最重的一记警钟。张鹏让陈晓第一次真正明白"杠杆是会死人的"，彻底戒掉加杠杆的念头。死法是"杠杆爆仓"：一夜之间突然死，连反悔的机会都没有。
- **关键台词**：
  - "陈晓，你太怂了，看准了就要梭哈，不然什么时候才能翻身？"
  - "没事，扛得住，我算过了，最多再跌两天就反弹。"
  - "（爆仓后）兄弟，我什么都没了……老婆孩子都走了……"

### 6. 刘建国（刘哥）——最重的悲剧（失败·挪用公款配资入狱）

- **身份**：陈晓打工时的部门主管，40岁左右，有车有房有家庭，日子安稳本分。
- **性格**：老实本分了一辈子，却被牛市冲昏头，想"搏一把翻身"，动了不该动的钱。
- **炒股风格**：一开始小打小闹，嫌慢；后来挪用公司采购款/货款，配资炒股，越陷越深。
- **命运线**：
  - 2020.7 牛市，小资金赚了点，开始加码，动了"用公司的钱炒一把"的念头。
  - 2021年 挪用公款 + 场外配资，一度大赚，尝到甜头，窟窿越补越大。
  - 2022年 熊市爆仓，公款亏空几十万，东窗事发，公司报警，被立案、判刑入狱。
- **结局**：入狱，妻离子散，人生彻底毁掉。是全书"炒股炒到坐牢"的极端警示。
- **作用**：最重的一记耳光。刘哥让陈晓明白：**赌博式炒股不仅会亏光自己的钱，还会把整个人生、整个家庭都赔进去。** 死法是"挪用公款配资"：为了翻本，动用了不能动的钱，最终万劫不复。
- **关键台词**：
  - "陈晓，别告诉别人，我拿公司的钱炒的……就搏这一把，赚回来就还上。"
  - "（爆仓后）我完了……孩子还小，老婆要离婚，我这辈子算是交代了。"

### 7. 李岩（眼镜）——最普遍的悲剧（失败·跟单被割抑郁退圈）

- **身份**：淘股吧普通散户，30岁上班族，戴眼镜，斯文，性格怯懦。
- **性格**：没有主见，迷信"老师"，天天看大V喊单，跟着追涨杀跌，从不自己思考。
- **炒股风格**：完全跟单，别人说买就买，说卖就卖，没有自己的体系。
- **命运线**：
  - 2020-2021 跟着各路大V，小赚大亏，账户反复缩水。
  - 2022年 追高妖股，被割到本金亏光，借的钱也还不上。
  - 患上抑郁症，销号退圈，从此再没出现过。
- **作用**：无数跟单散户的缩影，也是陈晓"反对迷信、强调独立思考"的注脚。死法是"跟单被割"：把命运交给别人，最终被割到连命都差点没了。
- **关键台词**：
  - "陈哥，你说的这个票，我跟着买点行吗？"
  - "（最后）我不玩了……再玩下去，命都没了。"

### 8. 陈志强（表哥）——最扎心的悲剧（失败·卖房网贷倾家荡产）

- **身份**：陈晓表哥，35岁，在老家县城有房有车，开小超市，日子过得去。
- **性格**：老实本分，但耳根子软，被"股市造富神话"蛊惑。
- **炒股风格**：一开始被老乡拉进炒股群，跟着买，小赚后贪心膨胀，卖房、借网贷梭哈。
- **命运线**：
  - 2020年 被拉进"炒股致富群"，小赚，开始迷信"跟着庄家吃大肉"，偷偷向陈晓打听。
  - 2021年 卖房、借网贷加仓，一度翻倍，彻底失去理智。
  - 2022年 熊市爆仓，房子没了、网贷逾期、老婆离婚、孩子归女方，躲债跑路，至今没脸回家。
- **作用**：亲情线最扎心，让陈晓直面"身边最亲近的人被股市毁掉"。死法是"卖房网贷"：押上全部身家+借贷，最终一无所有、众叛亲离。
- **关键台词**：
  - "晓啊，哥这次是真看准了，卖了房跟你一起干，赚了大钱咱们一起风光。"
  - "（爆仓后）晓，哥对不起你，也对不起你嫂子……这日子，没法过了。"

## 四、写作要点（避免工具人化）

1. **三条成功路，各有各的代价**：陈晓的成功是"刀尖舔血"，阿凯的成功是"死过一次"，林薇的成功是"稳稳的幸福"。三种活法，三种游资，都不重样。
2. **五种死法，五种警示，层层递进**：
   - 老周 = 温水煮青蛙（不设止损，慢慢熬死）
   - 张鹏 = 杠杆爆仓（一夜归零，突然死）
   - 刘哥 = 挪用公款配资（动不能动的钱，万劫不复，入狱）
   - 眼镜 = 跟单被割（没主见，把命交给别人，抑郁退圈）
   - 表哥 = 卖房网贷（押上全部身家，倾家荡产、众叛亲离）
   - 加上龙套里的无数散户，共同构成"大部分亏损惨重"的真实底色。
3. **陈晓的态度要"复杂"**：对失败者，是"兔死狐悲"的恐惧（他知道自己和老周张鹏只差一个纪律）；对刘哥、表哥，是更深的痛（一个毁了人生，一个毁了亲情）；对阿凯，是"并肩又各自重生"的欣慰；对林薇，是"原来还有另一种活法"的敬意。
4. **后期要有"幸存者愧疚"**：陈晓越成功，越不敢面对这些失败者。第190章"圈内的背叛"、第216章"高处不胜寒"，都要有这些人完整群像的影子——山顶上，只剩他一个人。
5. **阿凯是全书最动人的弧光**：从"我一把超过你"到"我认了"再到"我现在睡得着觉了"，他完成了"赌徒→失败者→重生者"的蜕变，是"活下来才能翻盘"这句心法的活教材。
6. **林薇是唯一的暖色+智者**：她不是配角，她是"另一种正确答案"——在全员疯狂里，她始终清醒，最终全身而退。
7. **失败群像要"分散但贯穿"**：不要让五个失败者扎堆出场，而是分散在 2020-2022 的不同节点，各自有完整的起→贪→惨三段，避免脸谱化。

## 五、江湖对标：六一路（2024年神秘格局游资）

> 不是兄弟团成员，但必须单列——他是"格局"这个词的江湖奠基人，是陈晓的一面镜子。

- **身份**：2024年A股横空出世的神秘大游资，从不露面，龙虎榜上只留下"六一路"的席位代号，真实身份成谜（有人说是顶级游资的马甲，有人说是机构资金）。
- **风格**：**格局**。买入后锁仓不动、绝不砸盘，甚至主动让利给跟风盘，让跟风散户有安全感，从而形成"合力"，让个股持续打出新高度。
- **成名**：2024年在大众交通、深圳华强等妖股上以"格局"封神，被散户尊称"格局王"。他的席位一现身，次日个股大概率高开甚至涨停，散户疯狂跟风。
- **作用**：陈晓的镜子。2024年陈晓观察六一路，第一次见识"格局"的力量——顶级游资的最高境界不是自己赚最多，而是让跟风的人也能赚钱，从而把票推向极致。
- **结局**：留白。2024年底后，六一路的神秘席位逐渐消失，成为江湖传说。
- **意义**：六一路让陈晓悟出一个道理——**顶级游资拼到最后，拼的不是技术，是格局：能不能扛住不卖，让跟风盘相信你、跟随你，把一只票推向极致。** 这条线为2025年陈晓"靠格局出圈"埋下伏笔。

## 六、写作要点（格局线补充）

1. **格局的双重性**：格局是荣光（让散户赚钱、让游资封神），也是绑架（一旦想卖，跟风盘瞬间崩塌；玩到极致，就是"操纵市场"的罪名）。陈晓2025年的封神与2026年的塌房，本质是同一个东西的两面。
2. **六一路是"前传"，陈晓是"正传"**：2024年六一路靠格局封神，2025年陈晓靠格局出圈，两人形成"格局"的江湖传承。六一路神秘消失，陈晓重蹈覆辙又试图挣脱——这是全书最深的宿命感。
3. **格局 vs 割韭菜**：写"格局"时，一定要有"割韭菜游资"做反衬。同样是锁仓，格局是"我陪你扛"，割韭菜是"我出货你接盘"。散户分得清，所以才会疯一样跟风有格局的人。
