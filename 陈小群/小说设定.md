# 《游资是怎样炼成的》—— 最终设定

## 一、基础信息
- **书名**：《游资是怎样炼成的》
- **主角**：陈晓（化名，保留原型"陈"姓辨识度，名字完全独立）
- **原型**：陈晏群（淘股吧账号「心跳L」，席位大连金马路/中国银河证券），"情绪合力龙头"战法创始人
- **金手指**：无。靠悟性 + 极致复盘纪律 + 情绪周期认知（真实流）
- **题材类型**：都市 / 金融 / 草根逆袭 / 商战
- **发表平台**：番茄小说

## 二、主线（时间线全部踩真实 A 股行情节点）
- 起点：2020年初，陈晓几千块入市
- 终点：2025年12月，资金做到几个亿
- 核心脉络：韭菜被割 → 悟龙头 → 穿越牛熊 → 封神 → 巅峰抉择

## 三、真实行情节点（剧情骨架，全部可考证）
| 时间 | 真实行情 | 主角阶段 |
|------|----------|----------|
| 2020.3 | 疫情暴跌→放水修复 | 几千块入市，懵懂被割，第一课"空仓止损" |
| 2020.7 | 全面牛（券商/白酒） | 悟"只做最强"，抓券商龙头，资金破几万 |
| 2021 | 新能源/锂电/光伏大牛 | 专注赛道龙头，破百万；首次踩退潮回撤40% |
| 2022 | 熊市妖股打板活跃 | 修炼打板纪律（浙江建投/中交地产/特力A），穿越熊市 |
| 2023 | ChatGPT/AI 行情爆发 | 龙头战法成型，抓AI算力总龙头，破千万封神 |
| 2024.9 | 924行情政策转向放量疯牛 | 游资圈成名，破亿 |
| 2025 | AI应用/机器人/科技牛 | 资金数亿，胜宏科技闷杀，终极抉择 |

## 四、核心心法（贯穿全书的"阵法"）
- 情绪周期六阶段：**冰点 → 启动 → 发酵 → 高潮 → 分歧 → 退潮**
- 战法灵魂：**只做最强、冰点低吸、退潮空仓、高潮兑现**
- 原型真实语录（可直接化用）：
  - "龙头不是天天有，有就重仓干，没就耐心等"
  - "市场活了才有机会，市场死了再牛也得趴着"
  - "分歧就是换手上车机会，只要不出现放量跌停，就握紧筹码"
  - "高手买入龙头，超级高手卖出龙头"
  - "看空永远正确，做多才能赚钱"
  - "情绪冰点，都是买容量票的时机"

## 五、人物设定
- **陈晓**：普通家庭、普通学历，白天打工晚上复盘，性格弧光从"赌徒式追高"→"纪律机器"→"敬畏市场的王者"
- **配角可化名**：游资圈原型（赵老哥→赵三哥、炒股养家→养家老王等）

## 六、结构规划（约230章，6卷）
1. 第一卷 韭菜觉醒（2020，30章）
2. 第二卷 龙抬头（2021，30章）
3. 第三卷 熊市淬炼（2022，32章）
4. 第四卷 AI封神（2023，32章）
5. 第五卷 924惊变（2024，34章）
6. 第六卷 巅峰与抉择（2025，40章+结局）
